# 🐔 Almost There

A 2D parkour platformer where you play as a chicken climbing to the top of an obstacle course. Watch your step: some platforms are fake, and they'll drop you right through.

## Gameplay
- You need to use the W, A, D keys to guide your chicken up through the parkour to the finish line. This involves jumping inbetween platoforms, but be aware of false floors! Some platforms may look solid but give away when you land on them. This game is supposed to be temporary ragebaid :) 

## Controls

| Key | Action |
|-----|--------|
| A | Move left |
| D | Move right |
| W | Jump |
